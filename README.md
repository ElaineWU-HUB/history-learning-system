# 📜 历史系统学习平台

一个运行在本机的系统化历史学习平台：**中国史 × 世界史** 双主线，辅以**中外对照专题**，帮助历史基础薄弱的学习者从零建立完整的通史框架。整体采用「摊开的史书」书卷主题：书眉顶栏、书签缎带导航、书页正文、卷轴时间轴。

## 快速开始

用浏览器（Chrome / Edge / Safari）打开 `index.html` 即可，无需安装、无需联网、无需服务器。

- 学习进度保存在浏览器本地（localStorage）
- 建议路径：首页 → 按「学习循环」依次读 中国史单元 ↔ 世界史单元 ↔ 对照专题 → 在时间轴回顾

## 功能

| 模块 | 说明 |
|---|---|
| 学习路线图 | 24 个单元 + 6 个对照专题，按时代配对成 12 个「学习循环」，支持三种路线模式（并进对照 / 中国史先行 / 世界史先行） |
| 课程 | 每单元 3 课，正文约 2000 字 + 本课要点 + 关键人物 + 大事年表；逐课标记已读，自动保存进度 |
| 全书目录 | 左侧固定目录栏：全部单元与专题默认展开，点击直达对应页，当前页高亮；窄窗口收纳为顶栏抽屉 |
| 中外对照时间轴 | 三轨展示（中国史 / 世界史 / 对照专题），滚轮缩放、悬停看年份、按单元过滤、点击查看事件详情 |
| 进度备份 | 设置页导出 / 导入进度 JSON，可跨浏览器迁移 |

## 如何扩充内容

### 把一个单元从「大纲」升级为「完整课程」

编辑对应文件（如 `content/china/c03.js`），做两件事：

1. `status` 改为 `'complete'`
2. 为每个 lesson 添加 `body`（正文）

正文格式：纯字符串，`\n\n` 分隔段落，`## 小节标题` 表示小节标题（小节会进入课程页左侧目录）。示例：

```js
body:
'## 秦的统一与中央集权\n' +
'公元前221年，秦王嬴政灭六国……\n\n' +
'## 皇帝制度\n' +
'……'
```

## ⚠️ 内容红线（必须遵守）

- **不得编造史实**。不确定的事实宁可不写，或明确说「学界存在争议」。
- **野史、民间传闻、传说必须标注**，不能当史实平铺直叙：
  - 正文/要点/解析中：用「传说」「相传」「据传」「未必属实」「传统说法」等措辞（例如「烽火戏诸侯」的传说未必属实）。
  - 大事年表与时间轴：传说性事件加 `legend: true` 字段，页面会自动显示「传说」徽标：

```js
events: [
  { year: '约前1046', title: '牧野之战', blurb: '…', detail: '…' },
  { year: '约前2000', title: '某某传说', blurb: '民间传闻，无实证', detail: '此说不见于正史…', legend: true }
]
```

- **史实分层**：信史（有文献+考古实证）、传统说法（史书记载但无同时代证据，如夏朝年代）、传说（炎黄、特洛伊木马计等）分别措辞。

### 添加新单元

1. 新建 `content/china/c13.js` 或 `content/world/w13.js`（复制现有文件改字段即可，注意 IIFE 结构与 `HC.units['c13'] = {...}` 注册）
2. 在 `content/curriculum.js` 的 `units` 数组中登记该单元元数据
3. 在 `index.html` 中加入对应的 `<script>` 标签（放在其他内容文件之后、`js/` 之前）

### 其他维护

- 事件的 `year` 格式：公元前用 `'前221'`，公元后用 `'589'`，约数加 `'约'` 前缀（如 `'约前1046'`）；时间轴会自动解析
- 新增事件会自动出现在时间轴与对应单元的大事年表中

## 开发与验证

```bash
cd scripts
npm install                 # 仅安装 playwright-core（复用系统 Chrome，不下载浏览器）
node validate-content.mjs   # 内容校验：全部课程/专题文件与总纲一致性
node visual-check.mjs       # 布局检查：溢出、渲染、时间轴轨道尺寸
node verify.mjs             # 浏览器端到端验证：页面渲染、进度持久化、时间轴、导出
```
